quiz Troubleshooting & FAQ

Common Desktop Extension Questions

Direct diagnostic steps for Chromium developer mode, privacy shields, and portal schema updates.

error_outline "Manifest file is missing or unreadable" during Load Unpacked

This occurs when selecting the outer archive folder instead of the inner unzipped package folder. When clicking Load unpacked, choose the folder that directly contains manifest.json and background.js, not its parent directory.

shield Brave Shields aggressive script blocking or Kiwi Android compatibility

In Brave, ensure Shields are set to standard rather than 'Aggressive' for student.bmsit.ac.in so standard synthetic events can dispatch. For Kiwi Browser on Android, enable Developer mode in kiwi://extensions and select the .zip file directly.

sync Updating extension when BMSIT portal alters DOM selectors

Because ContinueO uses deterministic state machine fallbacks and XPath heuristic matching, minor portal redesigns do not break execution. When an update is published on GitHub, simply replace the local folder contents and click the circular Reload icon on ContinueO in chrome://extensions.

Verify downloaded release zip directly from GitHub Releases to guarantee authenticity.
