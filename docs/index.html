Frequently Asked Questions

Answers & Technical Details

Everything you need to know about security, Play Protect, and automation mechanics.

How does 2-step automation solve the BMSIT portal quirks? expand_more

The BMSIT portal employs a two-tier verification workflow: Page 1 demands USN and DOB split across three legacy dropdown menus with trailing whitespace bugs ('01 '). ContinueO intercepts this by directly triggering the underlying putdate() JavaScript routine. When Page 2 loads, it detects the misnamed Joomla input name='otp' (which actually expects the ID card number), injects the stored credential, and triggers submission in under 2.5s.

Are my credentials secure on shared library computers? expand_more

Yes. The desktop browser extension allows locking your profile behind a 4-digit Master PIN. When locked, credentials in chrome.storage.local are AES-256-GCM encrypted using an encryption key derived via PBKDF2 (100,000 SHA-256 iterations). Without the PIN, the cipher payload cannot be read by anyone else using the computer.

Why does Google Play Protect show "Harmful app blocked"? expand_more

ContinueO is a community-driven open-source utility distributed directly via GitHub APKs rather than the Google Play Store (which requires paid developer organization subscriptions). Because it is signed with a self-generated developer certificate and automates web credentials, Play Protect flags it as an "Unrecognized developer". You can safely tap More Details > Install Anyway. The entire source code is 100% public and auditable on GitHub.

Can I download marks sheets and PDF notes directly in the app? expand_more

Yes! Default Android WebViews often drop session cookies during file download requests, leading to "Session Expired" blank screens. ContinueO intercepts PDF download intents and passes the active PHPSESSID session cookies and User-Agent headers to the Android system DownloadManager, storing documents directly in your Downloads directory.

How does Smart Tab reuse work in the browser extension? expand_more

Instead of opening duplicate portal tabs every time you click "Login", ContinueO scans your browser windows for an existing student.bmsit.ac.in tab. If located, it focuses and updates that active tab; if not, it instantiates a fresh window tab, preventing clutter.
